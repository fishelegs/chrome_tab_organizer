# 标签组助手

一个 Chrome Manifest V3 扩展，用于在弹出面板中管理当前标签页所在的标签组。

当前支持：

- 显示当前选中的标签组名称；如果当前标签页不在分组中，会显示“当前没有标签组”
- 标签组一键置顶：复制当前标签组到窗口最前面，然后删除原标签组
- 一键复制：复制当前标签组，并把副本创建在原标签组右侧
- 合并标签组并去重：选择当前窗口中的多个标签组，合并为第一个选中的标签组，并按网址去重
- 存档并收起：把当前标签组保存到插件同步存储，然后关闭原标签组
- 跨设备同步：同一扩展 ID、同一 Chrome 账号且开启 Chrome 同步时，存档会同步到其他电脑
- 两层存档结构：通过“文件夹 → 标签组存档”整理内容
- 新建、重命名和删除文件夹，并在文件夹之间移动存档
- 恢复单个标签组，或一键恢复文件夹中的全部标签组

复制、置顶、存档和恢复都会保留：

- 标签组名称和颜色
- 标签页网址及原有顺序
- 标签组的展开/折叠状态

“一键复制”不会修改源标签组；“标签组一键置顶”会在成功创建新标签组后删除源标签组；“存档并收起”会保存后关闭源标签组。

## 安装

1. 在 Chrome 地址栏打开 `chrome://extensions/`。
2. 打开右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本项目目录。
5. 建议把扩展固定到工具栏，方便打开面板。

## 使用

1. 切换到需要操作的标签组中的任意标签页。
2. 点击工具栏上的“标签组助手”按钮。
3. 在弹出的面板中选择“标签组一键置顶”、“一键复制”、“合并标签组并去重”或“存档并收起”。
4. 合并时打开“合并标签组”，选择当前窗口中至少两个标签组，可修改结果名称，然后点击“合并并去重”。
5. 合并默认按完整的 `http://` / `https://` URL 去重；Chrome 内置页面等非网页 URL 不自动去重。
6. 存档前可在“存入”下拉框中选择文件夹；也可以存入“未分类”。
7. 需要恢复时，在存档库中恢复单个标签组，或者点击文件夹的“全部恢复”。

也可以使用快捷键直接复制当前标签组：

- macOS/Windows/Linux：`Alt+Shift+D`

快捷键若与其他功能冲突，可在 `chrome://extensions/shortcuts` 中修改。

如果当前标签页不属于任何分组，面板中的操作按钮会被禁用；快捷键触发时会短暂显示“无组”；发生错误时显示 `ERR`。

## 同步和存档说明

- 存档优先写入扩展自己的 `chrome.storage.sync`，不是 Chrome 原生“已保存的标签页分组”。
- 同步需要多台电脑登录同一个 Chrome 账号、开启 Chrome 同步，并安装具有相同扩展 ID 的版本。
- “加载已解压的扩展程序”在不同电脑上可能产生不同扩展 ID。正式跨设备使用时，建议从同一个 Chrome Web Store 条目安装；开发阶段也可以配置固定扩展 ID。
- Chrome 同步存储约有 100 KB 总容量和单项 8 KB 限制。扩展会把标签页列表自动分片；同步写入失败时会安全回退到本地存储，并显示“仅本机”。
- 弹窗会显示同步空间用量以及仅本机存档数量。
- 旧版本保存在 `chrome.storage.local` 的存档会在首次升级时自动迁移；无法同步的旧存档会继续保留在本机。
- 点击“恢复”会在当前活动标签页右侧创建一个新标签组，并保留这条存档，方便重复恢复。
- 当前最多保留 100 条存档、30 个文件夹。

## 两层结构说明

Chrome 原生标签组不支持父子嵌套。扩展提供的是存档层的两层结构：

```text
工作项目（插件文件夹）
├── 需求调研（Chrome 标签组存档）
├── 开发资料（Chrome 标签组存档）
└── 测试页面（Chrome 标签组存档）
```

点击“全部恢复”时，子存档会恢复为多个相邻、并列的 Chrome 原生标签组；文件夹本身不会出现在 Chrome 标签栏中。

## 已知限制

- 复制的是当前窗口中已经打开的标签组，不是关闭后保存在“已保存的标签页分组”菜单中的组。
- Chrome 不允许扩展打开部分受保护的内部页面；若组内包含此类页面，本次复制会取消并清理已创建的副本标签。
- 网页的浏览历史、表单内容、滚动位置和登录页面的临时状态不会被克隆，只会重新打开对应网址。
- Chrome 扩展 API 目前不支持操作原生“已保存的标签页分组”的层级结构，也没有树状嵌套标签组能力。
- “合并标签组并去重”当前只处理同一个浏览器窗口中的标签组；去重只针对完整的 HTTP(S) URL，特殊页面会保留。
- `chrome.storage.sync` 不能直接告诉扩展用户是否开启了账号同步；关闭同步时，数据会留在当前电脑，待重新开启后继续同步。
